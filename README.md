# Kaggle Housing Prices

This project predicts home sale prices using the Ames Housing dataset from the Kaggle competition. The workflow includes exploratory analysis, feature preparation, multiple regression models, and final price predictions.

## What I Did
- Performed exploratory data analysis on the full dataset
- Created 5 visualizations to understand key housing features
- Cleaned and preprocessed data (missing values, encoding, scaling)
- Trained three models:
  - Linear Regression
  - Random Forest Regression
  - Neural Network Regression
- Fine‑tuned all models using scikit‑learn and cross‑validation
- Evaluated performance using RMSE and validation scores
- Generated final housing price predictions

## Repo Structure
- `notebooks/` — EDA, preprocessing, modeling, and predictions
- `data/` — sample Kaggle dataset
- `reports/` — housing price predictions / submission to Kaggle Competition

## Notes
- This project follows the Kaggle competition structure.
- All modeling was done using Python and scikit‑learn.
